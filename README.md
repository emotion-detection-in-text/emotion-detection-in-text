# Emotion-Detection-in-Text
This is CS4650-Natural-Language final project. Our topic is Emotion Detection in Text. The goal is to build and analyze model that can be used on a large scale and can correctly detect and classify moods across a wide range of text sources.

## Project Files

- **`Emotion-detection-in-text.ipynb/`**: Fine-tuned BERT model for Emotion Detection in text.
